## 🅿️ ParkSphere

### Smart Parking &amp; EV Charging Platform

ParkSphere is a web application designed to connect drivers with available parking spaces and EV charging services.

**Key Features:**

- 🚗 Parking discovery and booking
- ⚡ EV charging services
- 👤 Driver, Host and Captain roles
- 🅿️ Host parking listings
- 🚘 Captain valet service
- 📋 Booking management
- 📸 Valet pickup and parking evidence
- ⭐ Rating and review system

**Built With:**

`React` `JavaScript` `HTML` `CSS` `React Router` `Local Storage`
